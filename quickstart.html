🌐 Embedded Website Viewer

Enter any website URL to embed it with geolocation tracking

📋 What happens when you click:

1. Your IP address is fetched and logged to console
2. Browser requests your location permission
3. If granted, location data is logged to console
4. The website loads in fullscreen

🔍 Google 💻 GitHub 📚 Stack Overflow 📰 Hacker News

⚠️ Important Notes:

• Some websites block iframe embedding (e.g., Facebook, Twitter)
• Geolocation requires HTTPS in most browsers
• Check browser console (F12) to see all logs
• Open Developer Tools → Console tab to view IP and location data
